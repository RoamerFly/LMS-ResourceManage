立杰人力资源管理系统 LMS-ResourceManage v4.7.0

本版本由 GitHub Actions 在 Windows x64 环境中测试、构建并发布。

## 本次更新

- 电子表格支持区域复制粘贴、键盘移动、Backspace 框选删除、撤销重做、Ctrl+F 搜索及单元格聚光灯。
- 银行卡表和独立自定义表批量粘贴时自动扩展行数，行结构与普通资料跨月份同步；置空列按月份分别保存。
- 银行卡表保持模板样式并支持 XLS 导出；公共发行包提供空白模板。
- 切换月份或年份后保留当前工作表，目标月份没有该表时才返回默认表。
- 优化极简模式、人员卡片、部门管理及临时人员工作表。
- 工资按十进制计算并按分取整，统一前后端计算规则。
- 精简工具栏，导出按钮改为橙色；自建工作表标签右键可添加到其他月份。

## 下载与使用

下载 `LMS-ResourceManage-v4.7.0-windows-x64.zip` 并完整解压，运行其中的“立杰工资管理系统.exe”。不要只复制 EXE，须保留 `_internal` 目录。

需要 Windows 10/11 x64 和 Microsoft Edge WebView2 Runtime。`SHA256SUMS.txt` 可用于校验 ZIP。

## 旧版升级

1. 保存数据并关闭旧程序，先备份整个旧目录。
2. 将新版解压到新目录。
3. 将旧目录中的 `data.db`、`bank-card-template.xls`、`window_settings.json` 和 `fonts` 文件夹（如存在）复制到新版软件目录，再启动程序。

发行包不含用户数据库、人员工资或银行卡账号。首次启动会创建数据库；未放入私人银行卡模板时使用空白公共模板。请保留自己的模板及数据备份。
